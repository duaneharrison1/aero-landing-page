Bring it however you made it

Three ways in, and each one goes live at its own address.

  • One prompt from your chat: built it in Claude or ChatGPT? Copy one prompt into the same chat. It sends the files to Aero and the page updates when it’s live. Nothing to install.
  • Upload HTML: drop a single file, a folder or a zip.
  • Figma prototype link: Aero checks it, then publishes it with desktop and phone sizes. Changes in Figma show up on their own.
