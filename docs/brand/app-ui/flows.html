Start from Home

Mia has built Pocket in Claude. In Aero she clicks New. Nothing is saved yet.

Choose one prompt and copy it

One prompt is picked. She names it Pocket (address pocket.aeroapp.ai) and copies the prompt. Copying is the moment a draft is saved (proposed rule B7).

The prompt carries a one-time key, so the chat can publish to her account.

Paste it into Claude

She pastes it into the chat where Pocket was built. Claude calls Aero's publish tool with the files.

Claude's interface is drawn simplified and labelled. It is never inside Aero's frame. First time only: Claude asks her to connect Aero.

Aero is waiting

Back in Aero, the page waits and updates on its own. If she closes it, the site still appears under Sites.

Claude replies with the link

Claude confirms: live at pocket.aeroapp.ai, version 1. Seconds to a minute.

It's live, now test it

The page turns into the result: the address, the Publish, Test, Review line, and one next step. Proposed

The site page

Under Sites: live, version 1, offline in 7 days on Free, and Run a test on this site. Updating is a drop or another prompt; every update is a version.

Run a test on this site

From the site page, the one glass button. (Also from Home's "Now test it", or New, then Test an existing site.)

What testers try

Two tasks, a welcome and a thank-you. Screen and voice on. The preview shows the tester's first screen. Pinned to the version live now.

Or: explore freely

With no tasks, testers get one open prompt and decide when they are done. The tester never sees "0 tasks" (B15).

Land on Share, link copied

The Share tab opens, not Setup, with the link already copied. One link, a QR code, and what is recorded. Proposed

Someone else takes it

On her own computer. The tester screens are designed in the tester flow (screen 10). Only the tab she picks and her voice are recorded.

Recording now

Mia sees Session 1 appear live. Numbered from the first one, so it stays Session 1.

Transcript arriving

She finished at 07:12. The transcript follows, usually about a minute. Nothing types live.
