Aero app UI · step 1 · components

Tokens and components.

The small set of named pieces every Aero screen is built from. Each one uses only the tokens in tokens.css, and responds to its container, so the website and videos can reuse the same markup in a demo mode with example data.

Class names are stable: ae-component, ae-component--variant, is-state. Files: tokens.css, components.css, kit.py (helpers and the example scene). Switch palette at the top right.

Colour

Ink, white, mist and line do almost all the work. Aero blue is the one bright thing: the dot, links, selection and the playhead. Each area has one soft gradient, used for page headers, empty states and the website sections, never in the nav. Two palettes to choose from.

Glass: where it belongs

V3 glass (Snell refraction, Fresnel edge, key light), quiet by default, rounded rectangle in the app, pill when it floats. The engine reads each button's radius. Proposed rule: glass for the one primary action per view, floating player controls, and the tester task panel. Everything else is flat.

Primary actionV3 glass

One per view, in the page header or a modal footer. Ink glass, quiet: the rim takes a little colour from what is near it.

Over an area wash

On the share page the wash tints the rim. This is where the engine earns its place.

Floating player controlsProposed

Pills float over the recording, so they pick up the prototype’s colour. Shown on hover and when paused.

Flat, not glass

Secondary and tertiary buttons stay flat. Glass on everything is noise; on one thing per view it reads as "this is the next step".

.ae-guide
How the transcript is made
  1. The tester's voice is recorded with their screen.
  2. When they finish, the audio is transcribed, with a time for every word.
  3. The summary and friction points are written from that transcript. Quotes are their exact words.

Outside Aero

When a flow crosses into Claude or ChatGPT, it is drawn simplified, in its own colours and type, and labelled. Never in Aero’s components.

Rule

Aero never imitates another app’s UI inside its own frame. The flows show Claude as a separate step, with an "Outside Aero" label, before coming back to Aero.
