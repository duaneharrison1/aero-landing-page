# Aero brand folder

Everything about how Aero looks, sounds and is built, kept in the repo so it isn't lost in chat. figmaApp is the source; the same files are copied to `aero-landing-page/docs/brand/` (see the sync rule in `DESIGN_SYSTEM_PLAN.md` and both CLAUDE.md files).

| File | What it is |
|---|---|
| `DECISIONS.md` | Every decision Duane made, newest first. Read this first. |
| `BRAND.md` | Logo, colour, type, glass buttons, imagery. Current status. |
| `TONE_OF_VOICE.md` | How Aero writes, the product words, lines to reuse, truth rules. |
| `DESIGN_SYSTEM_PLAN.md` | Tokens, components, demo mode, marketing kit, two-repo sync, truth rules, order of work. |
| `PRICING-FACTS.md` | The only source for plans and limits in any copy. |
| `PLAYBOOK.md` | The process run on Aero, what differed from HeyBooking, lessons, links to every board. |
| `logo/` | Logo files (outlines). |
| `glass/` | The V3 glass button script, its source and the other variants studied, research notes. |
| `research/` | The strategy dossier, reference analysis, app UX review, conversation audit. |
| `mockups/` | The round 5 creative brief and the independent critique. |
| `directions/` | The UI directions stage: every main screen in A to D, flows, marketing kits, buttons and logo options. |
| `app-ui/` | The whole-app UI round: brief, then tokens, components, screens and flows. |
