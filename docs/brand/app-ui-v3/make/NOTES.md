## What changed in v3

### Shared stylesheet (`shared/aero.css`)
- **Sidebar `.sb-*`** (written first, class names stable, markup documented in the CSS comment). Today's sidebar improved: "Aero." with the collapse arrow beside it, no workspace name; Home, Sites, Tests; up to 5 recent tests under Tests with a state dot (blue new, green open, ring closed) and "Example" on the sample; plan meter above the account; bottom left avatar, name, email, labelled Example. Collapses to a 56px icon rail with `.app.rail` or `.sb.is-rail` (mark instead of lockup, arrow flips, meter becomes a line). `.sb-item.parent` marks Tests while one of its tests is open. The `.app` grid widens to 232px automatically when it holds a `.sb`.
- **Meter label is "Test sessions used"**, not "this month": PRICING-FACTS says never to write "a month" after session counts. Team B uses the same words. Sidebars on established accounts show "Pro plan, 15 of 20" to match Team B's sessions; first-run frames show "Free plan, 0 of 3".
- **Sample naming across the board:** my sample site is personalised ("Mia Chen's very serious portfolio") and its test is described as the sample test on Mia's site. Team B's frames call their sample test "Juniper". The names differ for now, as agreed with the coordinator.
- **GRADIENTS v3** (generated by `make/washes.py`, do not hand-edit): `--wash-publish` (peach, coral, apricot), `--wash-test` (sky, periwinkle, ice), `--wash-review` (mint, sky, a little butter), `--wash-hero` (all three), each in light and dark; `--in-*` card versions; `--grain` (fine SVG noise, put it first: `background:var(--grain),var(--wash-test)`); utility classes `.w-publish/.w-test/.w-review/.w-hero/.w-in-*`. Every blob fades on a smoothstep curve with 8 stops, so there is no banding; light washes have a white core so the middle stays luminous, never muddy. Dark warm washes lean rose rather than orange, because orange at low light reads as brown.
- **Site-tinted wash** `.w-site` / `.w-in-site` with `--site:<dominant colour>`: hue from the site, lightness and chroma fixed in oklch, a second blob 22° along the wheel, plus a touch of Publish peach. Coral, green, navy and yellow all land in one soft family (see g0). In dark it is a faint glow from the top edge.
