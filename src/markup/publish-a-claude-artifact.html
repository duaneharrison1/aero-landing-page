Publish a Claude artifact.

To publish a Claude artifact, copy one prompt from Aero into the Claude chat where you made it. Claude sends the files to Aero and it goes live at an address like yourname.aeroapp.ai. Or download the artifact as HTML and drop it into Aero.

About 2 minutesFree plan worksNothing to install

What you need

  • The Claude chat where you built the artifact
  • An Aero account (free)
  • Nothing else: the site name is optional

Steps

  1. 1

    Start a new site from a prompt

    In Aero, go to Sites, New site, and pick From Claude or ChatGPT. The name is optional: leave it blank and the site is named after its address.

  2. 2

    Copy the prompt

    Press Copy prompt. Copying it adds your personal publish key, so keep the prompt to yourself, like a password.

  3. 3

    Paste it into your Claude chat

    Go back to the chat where you made the artifact and paste it. Claude sends the files to Aero and replies with the address.

    Outside Aero · Claude, simplified
    Claude
    Publish this to Aero as a site called pocket. Use my Aero key: aero_sk_••••7Q2c …
    ● Used the Aero API · publish

    Done. It’s live at pocket.aeroapp.ai, version 1. Open Aero to see its page.

    Reply to Claude
  4. 4

    Open its page in Aero

    Aero sees the site go live and says so. Press Done to open its page: the address, a preview and its versions.

Prefer not to use a prompt?

Download the artifact from Claude as an HTML file, then drop it on New site, Upload HTML. It goes live at its own address the same way.

Test

Then test it.

On the site’s page, press Test this site. You get a test link to send to anyone: they open it on their own computer, and you get the recording, transcript and summary back.

How testing works

Questions.

Does my artifact stay on claude.ai?

Yes. Aero publishes a copy at its own address. Your chat and the artifact in Claude don’t change.

Can I use my own domain?

Yes, on Solo and up. Every site also has an aeroapp.ai address, and on Basic and up you choose its name.

How do I update it?

Ask Claude for the change in the same chat. On the site’s page, Ask Claude or ChatGPT gives you a prompt that publishes the next version to the same address. Aero keeps every version, so you can roll back.

Can I keep it private?

Add a password on Basic and up, so only people you give it to can open it.

Does it work with ChatGPT too?

Yes. The same prompt works in the ChatGPT chat where you built it.

How long does a free site stay live?

7 days, counted from when your first site goes live. Then it goes offline and keeps its address. Paid plans keep sites live, from $3 a month with a 7-day free trial.
