Paste a Figma link and Aero checks it.

Aero now turns a Figma design link into a prototype link, and tells you if the prototype is not shared.

Paste the link first. If it is a design or file link, Aero converts it. If Figma will not show the prototype to a visitor, Aero says so and shows how to share it, then checks again until it works.

What changed

  • Design and file links are converted for you
  • A warning when the prototype is not shared with anyone with the link
  • A short guide that re-checks as you change the setting
